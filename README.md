# frontier-earth

Web city sim: start in Alaska, expand across Earth.

## Palmer Bluff terrain concept

Open `index.html` in a browser to explore the interactive schematic of the Matanuska River bluff near Palmer. Drag to orbit, scroll to zoom, and adjust the vertical exaggeration, illustrative heat field, and water/wave display.

The terrain is procedurally sketched and is **not** a georeferenced elevation model or engineering design. It does not show measured or proposed ground changes. For site-accurate visualization, use an appropriate DEM and obtain the highway project's existing and proposed surface files from DOT&PF.
